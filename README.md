# React Profile Card

A modern, responsive React Profile Card built with React 18, featuring an animated avatar, interactive elements, and a stylish glassmorphism design. This project was created as part of the **Build a React Component** internship task.

## 🚀 Live Demo

**Live Website:** https://react-profile-card-rouge.vercel.app/

## ✨ Features

- **Responsive Design:** Adapts to different screen sizes.
- **Dark & Light Mode:** Switch between two visual themes.
- **Interactive Connect Button:** Toggle between connected and default states.
- **Animated Avatar:** Custom tech-inspired character with eye-tracking animation.
- **Glassmorphism UI:** Modern interface with translucent elements and visual effects.
- **Skills Section:** Displays HTML, CSS, and JavaScript.
- **Social Links:** Quick access to GitHub and LinkedIn profiles.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- React 18
- ReactDOM
- Babel
- CSS Animations


The project uses a single HTML file with React and supporting libraries loaded through CDNs. No npm installation or build setup is required.

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/duashah110/react-profile-card.git
   ```

2. Open the project folder:

   ```bash
   cd react-profile-card
   ```

3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code for local preview.
